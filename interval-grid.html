Tips & tricks
Notation key — adapted from LilyPond's input language
1. Notes are a sequence in time, not a grid address
  • There's no more beat number to type. Write positions in the order they happen; each one's duration (rule 2) tells the grid how far to advance before the next one starts — exactly like LilyPond's note input (c4 d e, not "beat 1, beat 2…").
  • A single note is one position character: RH uses 1–4 for lanes C1–C4 (root, 3rd, 5th, 7th); LH uses 1 (root/B1) or F (fifth/BF).
  • A chord is the position characters wrapped in <>, e.g. <123> = root+3rd+5th together — the same <> LilyPond uses for simultaneous notes. A bracket is required for more than one note at once; without it, digits would be impossible to tell apart from a duration number.
  • r is a rest — silence for its duration, needed now that nothing else advances the clock for you.
2. Duration — a number right after the position/chord, LilyPond-style
  • 1=whole, 2=half, 4=quarter, 8=eighth, 16=sixteenth, 32=thirty-second — each is "1 divided by the number," so 4 is a quarter of a bar.
  • It persists. Once set, later notes reuse it until a new duration is written — so 1 2 3 4 after an initial <123>4 are all quarters too, with nothing extra to type. This is the single biggest reason LilyPond input is fast to enter, and it works the same way here.
  • A trailing . dots the duration (×1.5); .. double-dots (×1.75). 4. = dotted quarter.
  • Before anything is specified, the default is an eighth note (8).
  • Each grid column is the largest of a quarter, 8th, or 16th that every note in both hands starts and ends on: only quarters (or longer) → quarter columns; any 8th or dotted quarter → 8th columns; any 16th, dotted 8th, or tuplet → 16th columns. Grid cells are always square, so finer columns make the grid wider rather than squeezing notes; wide grids scroll sideways.
  • A trailing ~ ties a note into the next one of the same pitch, shown as a bridge connecting the two blocks.
3. Bars
  • | is a bar check, same as LilyPond: it ends the current bar and starts the next. The number of bars shown is worked out automatically from your notation — one per completed |, plus whatever's left over after the last one — there's nothing to set manually.
  • If a bar's durations don't add up to a full 4/4 bar, a warning prints under it (e.g. "26/32 units") — the same idea as LilyPond's barcheck failure message, just phrased in 32nd-note units instead of beats.
4. Octaves — deliberately not LilyPond here
  • There's no more Absolute/Relative switch: a position digit always picks the same lane (2 is always the 3rd) and always sounds at that lane's own fixed default octave — never shifted automatically by whatever played before it.
  • This is a deliberate break from LilyPond, which auto-picks the closest octave to the previous note. Here, no marks means the plain, unmoved lane pitch every time — fully predictable, and never something to double-check.
  • ' shifts a note one octave higher than its lane's default; , shifts it one octave lower. Stack them for more ('' = two octaves up). Attach marks directly to a position, before the duration: 1'8. A mark is always measured from that fixed default, not from the previous note, so the same token always produces the same octave no matter what comes before it.
  • Inside a chord, each position carries its own marks independently — <12'3> is root at its default octave, 3rd shifted up one, 5th at its default. Nothing about one note in a chord affects another's octave.
  • Scale steps: > after a position moves it up one note of the key's scale (with the current chord's own tones swapped in — e.g. G# over E major in A minor), >> up two; < / << move it down one / two. On a C major chord in C Major: 1>> = E, 1> = D, 3< = F, 4> = the C above, 1< = the B below. Write steps after any octave marks and before the duration (1'>>8.); they work inside chords too (<1>>23>). The block stays in its lane's row, nudged 1/8 of a cell up (or down) per step, and shows one full-height arrow per step (↑ up, ↓ down). At most two steps per note — every scale note is within two steps of some chord tone.
  • Positions are chord tones, so the actual note depends on the chord: 2 is the chord's 3rd (E over C, C over Am, E# over C#), and 4 is its 7th — the chord's own 7th for a seventh chord, otherwise the key's 7th above the root. In Manual mode every bar uses the key's tonic chord; in Automatic mode each bar uses its own chord.
  • Hover any block to see its resolved note name, spelled for the key (Bb in F Major, E# in C# Minor).
5. Repeats and tuplets — borrowed from LilyPond's own \repeat and \tuplet
  • \repeat N { tokens } — plays everything inside the braces (one token or a whole phrase of them) N times in a row, exactly as if you'd typed it out that many times — duration keeps persisting across each repetition, same as anywhere else. Simplified from LilyPond's \repeat unfold N {…}: this tool only has one kind of repeat, so there's nothing for the unfold keyword to disambiguate.
  • \tuplet 3/2 { a b c } — a triplet: fits exactly three positions into the time of two of the currently-persisting duration (e.g. three notes in the space of two 8ths = one beat). Only 3-against-2 is supported.
  • Dropped from the previous version: the old \arp command is gone — duration persistence already makes writing an arpeggio as plain sequential notes just as short (<123>8 1 2 3), so a separate command added nothing.
6. Swing & chord quality
  • The Swing toggle nudges every straight-8th "and" slightly later for a long–short feel. It's cosmetic only and doesn't change duration math or the bar check.
  • Chord quality comes from the chord, not the notation: the same pattern gives a minor 3rd over a minor chord and a flat 7th over a dominant 7th, so one pattern works for every chord in a progression. LilyPond's own \chordmode (c:m7, c:maj7…) names chords the same way; this tool still keeps lane-by-lane voicing, since showing how a chord is voiced is the point.
7. Modes
  • Manual — pick and edit styles freely. Changing Key transposes the chord progression by Roman numeral (C – Am – F – G in C Major becomes G – Em – C – D in G Major, or Am – F – Dm – E in A Minor).
  • Automatic — the refresh button picks a key, a 4-chord progression and a style's pattern from the three sliders; the pattern repeats once per chord, one chord per bar. Only Tempo and Feel can be changed.
  • Key (1–10) picks a key at exactly that level: 1 C · 2 F, G · 3 Bb, D · 4 Eb, A · 5 E, Ab · 6 Db, B · 7 Gb, F# · 8 Dm, Am, Em · 9 Gm, Cm, Fm · 10 Bm, F#m, C#m, Bbm, Ebm, G#m.
  • Chords (1–4) draws from every level up to the slider and always includes at least one chord from that level: 1 I, IV, V · 2 ii, vi, V7 · 3 iii, vii° · 4 diatonic 7ths plus a dominant 7th on any degree. Progressions start on the tonic. Minor keys use minor-key harmony with a major V (i, iv, V in A Minor = Am, Dm, E).
  • Patterns (1–10) uses any style whose difficulty is at or below the slider, preferring styles at exactly that level. Styles with notation errors or incomplete bars are skipped.
